# Reliability-50：受控在线评测证据

## 文件

- `live_eval_reliability50_report_final6.json`：汇总报告。
- `live_eval_reliability50_trace_final6.jsonl`：逐任务请求、工具调用和响应轨迹。
- `browser-evidence/`：仪表盘、A2A 页面和登录页的真实浏览器渲染截图。

## 本次运行的真实统计

- 50 个 HTTP 任务：43 个工具任务、7 个 JSON Schema 结构化输出任务。
- 49 次实际工具调用：35 个单工具任务 + 7 个两步任务（14 次调用）+ 1 个允许安全拒绝且不调用工具的任务。
- 78 个工具参数字段被核对。
- 该次受控运行得到：工具选择 43/43、参数字段 78/78、无多余调用 0/49、结构化合约 7/7。

## 结论范围（重要）

这是一套**明确、可判定**的在线一致性/回归测试。引擎会对某些明确、只读、低风险意图执行服务端参数规范化和确定性约束；因此该报告验证的是“部署后的完整系统能否按既定规则执行这些任务”，而不是裸 LLM 在任意自然语言下的泛化能力。

因此，`100%` 只能解释为**这一次、这 50 条固定任务的结果**，不能解释为所有用户输入、所有模型波动或所有外部工具故障下永远 100%。后续需要增加与规则不重合的盲测改写集、多次重复运行和故障注入，分别报告均值、方差、连续成功率和失败恢复率。
