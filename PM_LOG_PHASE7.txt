### Changes Made
1. **app.py** — Added request-level middleware: each request generates `X-Request-ID` (uuid4) + `X-Response-Time` header; unified structured error contract `{status, code, message, request_id}` replaces FastAPI's default `{detail}`; 429 rate-limit also includes traceable request_id; `/api/chat` passes `{request_id, input_hash, start_time}` context to engine.run()

3. **metrics.py + observability.py** — Both MetricsCollector classes now have `_events` list with `record_event(event_name, *, request_id, duration_ms, tags)`, `get_events()`, `clear_events()`

4. **auth.py** — `DEV_AUTH_BYPASS=1` loopback bypass fixed to only allow real IPs (127.0.0.1, ::1); TestClient/host="testclient" no longer treated as loopback
